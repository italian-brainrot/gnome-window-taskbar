# Window Taskbar (GNOME Shell extension)

Taskbar for GNOME Shell based on **App Icons Taskbar (aztaskbar) v31.4** (GPL-3.0,
Copyright azaech). Derivative work: favourites stay app icons (no labels), while
open windows are shown as **individual, ungrouped buttons with window titles**.

See `HACKING.md` for the fork notes and `AUTHORS`/`LICENSE` for upstream licensing.
